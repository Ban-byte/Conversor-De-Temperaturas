#  Conversor de Temperaturas

##  Objetivo do Projeto
Este projeto tem como objetivo criar uma aplicação web simples e funcional que permita ao usuário converter valores entre diferentes escalas de temperatura: Celsius, Fahrenheit e Kelvin.  

A proposta é oferecer uma interface intuitiva e responsiva, ideal para fins educacionais, estudos de programação front-end ou uso cotidiano.

---

##  Descrição das Funcionalidades
- Conversão entre Celsius, Fahrenheit e Kelvin.
- Validação de entrada para evitar erros de cálculo.
- Interface limpa e responsiva, adaptada para desktop e mobile.
- Feedback visual para resultados e campos preenchidos.

---

##  Tecnologias Utilizadas
- **HTML5**: estrutura da página.
- **CSS3**: estilização e responsividade.
- **JavaScript (Vanilla)**: lógica de conversão e interatividade.

---

##  Instruções para Execução do Projeto
1. Clone ou baixe os arquivos do projeto.
2. Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Firefox, Edge, etc.).
3. Digite o valor da temperatura e selecione as escalas de origem e destino.
4. Clique em "Converter" para visualizar o resultado.
